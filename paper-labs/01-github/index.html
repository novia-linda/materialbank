01

Anslut ditt privata repository

Fyll i repository och GitHub-token. Ingen information lagras efter att sidan stängts.

Exempel: novia-linda/datareport — ange det exakta namnet som står i GitHub.

Klistra in token här i appen, aldrig i ChatGPT. Den används endast i anrop direkt till api.github.com.

Inte ansluten
Privat från början.

Appen accepterar endast ett repository som GitHub bekräftar är privat. PAT sparas inte i cookies, localStorage, sessionStorage, IndexedDB eller GitHub-filer. All appkod ligger offentligt, men inga personliga projektdata gör det.
