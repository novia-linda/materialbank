Google setup and update-test guide

Open the Evidence Lab

Use a personal Google account, Gemini in a desktop web browser, Drive and Sheets. The assignment does not require you to buy a plan. Menus and account limits can change; the fallback routes below protect your work without pretending that an unavailable feature succeeded.

First do Start here in the reporting app. That technical rehearsal needs no Gemini account: two images, your name, a few words and one checkbox. The demo PDF is not submitted.

1. Keep the three workspaces separate

WorkspaceWhat belongs there
Gemini web appYour saved Gem; a separate ordinary chat for analysing the email and call files.
Your DriveYour working copies of the policy, FAQ and register. Keep the same Google account open.
Evidence LabYour own observations and screenshots; local draft and downloads, not a cloud account.

2. Create and update your Gem

  1. Open Gemini in your browser. Use the sidebar: Gems → New Gem.
  2. Give it a name and enter your own instructions. Under Knowledge → Add files, add your working policy. Save the Gem.
  3. Use that saved Gem for the tests. When updating knowledge later, edit this Gem rather than creating a new one. Keep source citations enabled if the option is available.

Interface reference: Google: create, use and edit Gems. A file in one ordinary chat is not the same as a source saved in the Gem. This course deliberately makes you maintain the saved configuration.

3. Work with your own register in Sheets

  1. Download 04_Order-Register.xlsx from the Level 3 instructions and upload it to your own Drive.
  2. Open the Excel file in Sheets. Use File → Save as Google Sheets to create a native Sheets version. Give this working copy a recognisable name.
  3. There are now two files. Continue in the native Sheets copy, not the unchanged Excel upload. Inspect the Read me, Orders and Data dictionary tabs.

Conversion creates a separate Sheets file; it does not change the original Excel upload. Reference: Google: Excel and Sheets.

4. Try adding the working Drive source

In the Gem Knowledge area, try Add from Drive and select the same working register you are editing. Google requires Keep Activity and a Google Workspace connection for this route. If prompted, review the connection before proceeding. Use only the fictional training files. Google reference.

If your account does not offer the register in the picker, or the file is not read usefully, do not buy a subscription. Use the manual-file route below and record the limitation. This exercise does not require the paid Gemini sidebar inside Drive or Sheets.

5. Run the update experiment without guessing what happened

  1. Make the required change in your working Sheet and confirm that the file has saved. Keep a screenshot of the changed row or field.
  2. Ask the specified question in a new conversation with your saved Gem. Do not paste the new answer into the test chat.
  3. Record the actual reply. Continue with another task, then optionally try once more and record the approximate wait. A correct-looking answer alone is not proof that the updated file was read.
  4. Distinguish: found without re-upload; not found; found only after manual re-upload; or unclear. Correctly record failures as well as successes.

Google says a Gem uses the most recent version of a source added from Drive, but it does not specify a guaranteed one-minute refresh time. This is a source-update experiment, not a certified live-system connection. Google reference.

6. Manual-file fallback

  1. In the edited working Sheet, use File → Download → Microsoft Excel (.xlsx). Add that new export to the Gem and remove the superseded register snapshot from its active knowledge.
  2. If XLSX cannot be read, export the current Orders tab as CSV. Alternatively, copy the relevant updated rows with their column headers into a clearly labelled text file.
  3. Retest and record manual re-upload. Do not describe a successful manual replacement as proof of automatic refresh.

Do not re-add the original course TXT/CSV after an edit and expect it to contain your changes. Those downloads are baseline snapshots. References: Google: supported uploads; Google: exporting a spreadsheet.

7. Privacy, limits and a practical stopping rule

Personal Gemini account data is governed by Google's consumer terms and privacy controls. Activity settings affect data use; do not treat the account as an approved environment for real customer information. All course records are invented. Do not include passwords, account menus or real customer details in screenshots. Google: Gemini privacy.

If you encounter a temporary quota or account restriction, save a backup and your source files. Retry later or use the course fallback and explain the obstacle. Do not report invented AI results. The teacher assesses the work and evidence, not your ability to remove a service restriction.
