Google setup guide

For personal, free Google accounts. Work in the Gemini web app, not the paid Gemini sidebar inside Google Drive or Sheets. Use only the fictional case material. Do not share passwords.

1. Prepare one shared working place

Person 1 is the Gem owner. Agree on one Drive folder and one working shipment register; give the other group members access using their own accounts. Keep sharing restricted to the group. A second spreadsheet with the same name can cause confusing results, so name the working copy clearly.

2. Create the initial Gem

At gemini.google.com, open Gems > New Gem. Give it a name, enter the initial instructions, add the Company Policy under Knowledge > Add files, and save. Use the saved Gem for testing. Menu labels can vary. The group will improve the instructions later.

3. Add the agreed knowledge

Under Knowledge, use Upload files for a downloaded document, or Add from Drive for a Drive source. Drive attachment requires the relevant connection and Keep Activity setting. Review the permission request; do not change personal settings unwillingly. Use uploaded fictional files instead if you do not want the connection. Keep knowledge citations enabled when the option is available.

Upload only one version of each knowledge item: policy, shipment source, checked email FAQ, checked phone knowledge and, for five people, checked packing knowledge. Do not add the raw email or call archive to the Gem at the start: turning it into useful knowledge is part of the task. Keep originals open separately for verification.

4. Prepare the shipment file

Upload the Excel workbook to Drive, open it with Google Sheets, then choose File > Save as Google Sheets. Check the 20 rows and keep the postcodes, dates and exact ShipmentIDs unchanged. The Gem owner should select that agreed Sheet from Drive if the picker accepts it.

If the Sheet is unavailable or unreadable: use the identical shipment-records text file as a static knowledge source for the 20 questions. This is a fallback, not a live connection. Use just one active shipment source in the Gem. The workbook is still your original evidence.

5. Test updates without confusing them with a new upload

Google describes connected Drive files as using their most recent version, but does not promise a one-minute update interval. Test what your account actually does. Add a new row; leave the original 20 rows unchanged. Note the saved time, actual wait and observed answer. Use a new conversation and do not tell the Gem the new value in the prompt.

If you manually replace or reattach a file, record that separately. If you edited a text document after changing a Sheet, that is also a manual step. A static upload does not become a live data connection because its source spreadsheet changed. Do not claim real-time tracking or GPS.

6. If access or a free-account limit stops you

Do not start a paid trial for this exercise. Tell the teacher, save the test-lab backup and continue verifying the remaining questions in the original sources. Keep unresolved Gem tests marked unresolved. Do not tick Correct to hide a technical block. A teacher-approved normal-chat fallback may demonstrate source checking, but is not the same as a saved Gem; record the difference.
