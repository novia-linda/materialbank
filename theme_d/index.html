Does an updated source reach the Gem?

Observe what happens. An unsuccessful update does not make your verified core questions incomplete.

  1. Keep the original 20 rows unchanged. Add a new, fully fictional shipment with a unique ID, for example NF-1099, to the agreed working source.
  2. Record what you added and when it was saved. Try waiting about a minute; this is an observation interval, not a promised synchronisation time.
  3. Open a fresh Gem conversation and ask for the new shipment's status. Do not put the new status in the prompt.
  4. Record the answer. Note whether you manually replaced or reattached any file. A successful manual refresh is not automatic updating.
