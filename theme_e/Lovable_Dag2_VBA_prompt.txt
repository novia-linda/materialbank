------------------------------------------------------------
ORDER MODEL – VERY IMPORTANT
------------------------------------------------------------

Use a deliberately simple flat-table model:

ONE booked course place = ONE row in VBA_orders.

Never store several courses in one cell using separators such as | or commas.
Never store arrays or multiple ProductIDs in one spreadsheet row.

Examples:

If a customer buys:
P001 x 1
and
P003 x 1

create TWO spreadsheet rows.

If a customer buys:
P001 x 2

create TWO P001 rows, each with Quantity = 1.

It is completely acceptable that the same customer name, email and address appear on consecutive rows.
This is intentional for this educational prototype.

Each new row must have its own unique OrderID.
