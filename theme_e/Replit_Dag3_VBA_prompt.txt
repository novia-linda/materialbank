7. STATUS UPDATE
------------------------------------------------------------

This is the most important Day 3 function.

Staff must be able to change the status of an order.

Canonical values stored in Google Sheets must remain exactly:
- New
- Reviewing
- Confirmed

When the app is in Swedish, display them as:
- New -> Ny
- Reviewing -> Behandlas
- Confirmed -> Bekräftad

When the app is in English, display:
- New
- Reviewing
- Confirmed

IMPORTANT:
Always save the canonical ENGLISH value to Google Sheets, even when the user interface is Swedish.

When staff changes Status:
1. identify the correct row using OrderID
2. update only the correct order row
3. save the new canonical Status value to VBA_orders
4. update LastUpdated to the current timestamp
5. show a clear success message
6. refresh the visible order data so the new status is immediately visible

If the update fails:
- do not pretend it succeeded
- keep the previous status visible
- show a clear bilingual error message
