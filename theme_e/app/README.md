# Nordic Freight Group App Launcher

Static GitHub Pages app for the AI for Business Nordic Freight group case.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and the `assets` folder to the repository root.
3. In **Settings -> Pages**, choose **Deploy from a branch**.
4. Select the main branch and root folder, then save.
5. Open the generated GitHub Pages URL and add that link to Moodle.

## Student workflow

- Choose a 4-person or 5-person group.
- Paste each published student-app URL.
- Click **Create Nordic Freight landing page**.
- Each role opens in a new browser tab.
- Use **Save backup** to download a JSON copy of the configuration.
- Use **Load backup** to restore the configuration on another computer/browser.
- Use **Edit links** when a published URL changes.

The setup is stored only in the browser's localStorage. No student links are sent to a server by this page.
