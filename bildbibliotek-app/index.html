Snabbhjälp

1. Klistra in skärmbilder med Ctrl+V. Du kan ha flera bilder samtidigt.

2. Använd Steg för numrerade klick, Fokus för att tona ned bakgrunden, Zoom 2x för små menyer och Maskera för att täcka känslig data.

3. Välj format och färdig pixelstorlek. Med Hela bilden + marginal försvinner ingen information.

4. Spara redigerbart projekt (.json) om du vill kunna flytta dina pilar eller ändra texten senare.

5. Välj Anslut till GitHub med en begränsad nyckel. Chrome kan erbjuda att spara den som lösenord. Nyckeln används bara i webbläsarens minne och lagras inte av appen.

6. Installera appen från Chrome-menyn eller knappen Installera app. Det kräver normalt inga administratörsrättigheter.

Genvägar: A pil, R ruta, N nummer, T text, H markering, S fokus, Z zoom, M maskera, C beskär, V flytta, Ctrl+Z ångra.

Viktigt: Använd en helt täckande maskering för verkligt känslig data. Förhandsgranska varje bild innan du laddar upp till ett offentligt repo.
